# Engineering Apprenticeship

A 52-week engineering apprenticeship focused on understanding, implementing, testing, measuring, and explaining software systems.

## Purpose

This repository contains cumulative engineering laboratories, focused investigations, experiments, and project milestones developed throughout the apprenticeship.

The goal is to build engineering judgment through first-principles reasoning, implementation, testing, measurement, comparison, and technical writing.

## Working method

For each investigation:

1. Establish the problem and assumptions.
2. Study the relevant primary sources.
3. Implement or model the mechanism.
4. Test normal, boundary, and failure cases.
5. Record observations and evidence.
6. Compare alternatives and document trade-offs.
7. Publish a technical explanation linked to the implementation.

## Repository map

- `labs/` - Working implementations and tests.
- `investigations/` - Daily research notes and evidence.
- `projects/` - Larger systems built across multiple lessons.
- `reports/` - Weekly and milestone reviews.
- `decisions/` - Engineering decisions and trade-offs.
- `references/` - Sources consulted during investigations.
