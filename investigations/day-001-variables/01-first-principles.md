## Investigation question

What problem do variables solve, how do they work in Java, and what changes when the system or requirements change?

## Initial hypothesis

A variable provides a name through which a program can refer to a value. Names allow the program to express computations and make decisions without rewriting the value at every use.

This hypothesis will be refined after reading the sources and running the laboratory.
